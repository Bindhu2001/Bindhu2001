## 🚀 Featured Work

### 🧑‍💼 RIZO HRMS: Web Platform
> Next.js · React · TypeScript · Tailwind CSS · MySQL · Zod

- Admin portal + Employee Self-Service (ESS) portal
- Employee database, attendance, leave, payroll and salary structures
- Offer letters and onboarding flow (Join → Onboard → Salary allocation)
- Role-based logins, plan/subscription control, transactional emails

### 🤖 Ask RIZO: AI HR Assistant
> OpenAI API · Function calling · TypeScript · Rule engine

- Chat assistant that understands HR questions and calls real app functions (tools) to fetch live data
- Multi-step tool chaining that follows the hiring flow
- **124+ automated test scenarios** to keep answers accurate

### 📱 RIZO Mobile App
> React Native · Expo · EAS Build · Firebase Push Notifications

- Attendance punch-in, leave requests and customer-visit tracking
- Published on **Google Play** and the **iOS App Store**

### ⚡ Punch Queue Service
> Node.js · Fastify · RabbitMQ · MySQL · DigitalOcean

- Ingest → queue → worker pipeline for mobile attendance punches
- Retry, failed-message replay and multi-tenant routing
